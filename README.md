# 工科本科论文指导 · Engineering Thesis Coach

面向中文理工科本科生的跨平台 AI 写作技能，陪你完成选题、文献综述、开题、研究设计、逐章写作和修改。每个阶段都有可检查的成果，并通过论文进度摘要衔接后续工作。

核心指令保存在 [SKILL.md](engineering-thesis-coach/SKILL.md)，采用 [Agent Skills 开放规范](https://agentskills.io/specification)中的目录与元数据结构。正文可作为普通对话指令复用，不依赖特定 AI 厂商、API、运行环境或付费服务。

## 怎么使用

### 普通 AI 对话：复制粘贴

适用于你使用的、支持中文长文本指令的 AI 聊天应用：

1. 打开 [SKILL.md](engineering-thesis-coach/SKILL.md)，复制从“工科本科论文指导”标题开始的全部正文。开头两条 `---` 之间的名称、描述和许可证是元数据，不必复制。
2. 将正文粘贴到新对话，并在末尾加上自己的需求，例如：

```text
请把上面的内容作为本次对话的论文指导流程。
我是计算机专业本科生，现在还没有确定题目，距离开题还有一个月。
请从当前最关键的问题开始问我，先帮助我确定可行方向，不要直接生成整篇论文。
```

如果应用能够读取 Markdown 附件，也可以上传 `SKILL.md` 并发送上述要求。仅上传附件不代表应用会自动采用其中的流程。

### 支持 Agent Skills 的应用：加载技能文件夹

按照所用应用的安装文档，导入或放置整个 `engineering-thesis-coach/` 文件夹，保留其中的 `SKILL.md` 文件名。如果应用要求 ZIP，请将该文件夹打包，使解压后的顶层是 `engineering-thesis-coach/`，其中包含 `SKILL.md`。不要直接把整个 GitHub 仓库的下载包当作已经打包好的 Skill。

然后明确提出：

```text
请使用 engineering-thesis-coach 技能，帮助我开始本科毕业论文。
先了解我的专业、已有材料和当前阶段，再指导下一步。
```

安装位置、导入入口与触发语法以各应用文档为准；没有原生 Skills 功能时，使用上面的复制粘贴方式。

## 换模型或开新对话

阶段结束时保存 AI 更新的“论文档案”。在另一个模型或新对话中，重新提供本 Skill 的正文和最近的论文档案，并补上当前任务需要的论文材料。Skill 文件承载流程，论文档案承载进度；两者不会自动在平台之间同步。

## 能力与适用范围

- 基础指导通过文字对话完成，无需运行代码或配置 API 密钥。
- 有联网能力时可搜索和核验来源；没有时提供检索指导，并分析你提供的资料。
- 有文件权限时可保存草稿和档案；没有时输出可复制文本。
- 不假定能执行实验、运行代码、读取任何附件或记住其他对话，不编造文献、数据或结果。

“跨平台”指同一套写作指令可以复用。原生技能加载由应用决定；不同模型的指令遵循、上下文容量和工具能力会影响效果，不能保证所有模型功能或表现一致。本项目尚未逐一在各家模型与应用中验证。
